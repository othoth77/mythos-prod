# mythos-smart-data-entry

## What this skill does

When a task requires entering or generating structured data for a Mythos product, consults the relevant product's canonical identifier registry and data governance document (e.g. `docs/AUTOMOTIVE_DATA_GOVERNANCE.md`) before inventing a new field name or shape, so new data stays consistent with existing conventions across the ecosystem.
