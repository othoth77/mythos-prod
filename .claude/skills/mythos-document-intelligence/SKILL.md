# mythos-document-intelligence

## What this skill does

Assists with document-shaped tasks (preparing, formatting, or reasoning about a document) consistent with:
- the `document.prepare` capability contract defined in `docs/MYTHOS_DOMAIN_PACKS.md`,
- the existing production `Documentation` module conventions already present in the Mythos Prod application (`js/shared/documentation.js`).

Does not implement a new document format or storage convention without checking these first.
