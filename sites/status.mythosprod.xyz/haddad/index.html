Live monitoring

MYTHOS HADDAD — AI compute node

Real state, pushed by the node every 10 seconds and published here. This page is read-only: it cannot run a command, restart a service, change a configuration or reach the node at all. The VPS holds only each node's public key and never opens a connection to it. A value the node could not measure is shown as N/A — never as zero, never guessed. If the heartbeat stops, the state you see is recomputed in your browser, so a frozen file can never keep a node green.

هذه الصفحة تعرض حالة العقدة الحقيقية: العقدة هي التي ترسل بياناتها كل عشر ثوانٍ، والخادم لا يتصل بها أبداً. الصفحة للعرض فقط — لا تشغّل أوامر ولا تعدّل شيئاً. وأي قيمة لا تستطيع العقدة قياسها تظهر N/A ولا تُخمَّن. وإذا انقطع النبض تُحتسب الحالة من جديد داخل المتصفح، فلا يمكن لملف قديم أن يُظهر العقدة سليمة وهي متوقفة.
